# C# SDK для Docmost API

## Что сделано

- Создана NuGet-ready библиотека `Docmost.Sdk` в `c#/src/Docmost.Sdk/`
- Solution: `c#/Docmost.Sdk.sln`
- Генератор из OpenAPI: `c#/scripts/generate_sdk.py` (модели + 23 API-клиента по тегам)
- Аутентификация:
  - **API token**: `Authorization: Bearer`
  - **Email/password**: POST `/auth/login`, сессия через `CookieContainer`
- `DocmostClient` — фасад с группами `Auth`, `Users`, `Workspace`, `Spaces`, `Pages`, …
- `ApiResponseExtensions` — десериализация `Data` в типизированные модели
- Сборка и pack: `dotnet pack` → `c#/artifacts/Docmost.Sdk.1.0.0.nupkg`

## Структура

```
c#/
  Docmost.Sdk.sln
  README.md
  scripts/generate_sdk.py
  src/Docmost.Sdk/
    DocmostClient.cs
    DocmostClientOptions.cs
    Http/DocmostHttpClient.cs
    Models/   (109 DTO)
    Services/ (23 API classes)
    Json/ApiResponseExtensions.cs
```

## Публикация NuGet

```bash
cd c#
dotnet pack src/Docmost.Sdk/Docmost.Sdk.csproj -c Release
dotnet nuget push artifacts/Docmost.Sdk.1.0.0.nupkg --api-key <KEY> --source https://api.nuget.org/v3/index.json
```
